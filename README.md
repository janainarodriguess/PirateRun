
# PirateRun

Jogo 2D do gênero runner, com temática de piratas e exploração de uma ilha perdida.

## Objetivo

O jogador controla um pirata que está perdido em uma ilha e precisa correr em busca do mar para escapar em seu barco.

Durante o percurso, o jogador deve desviar de obstáculos, coletar moedas e encontrar baús de tesouro, que valem mais pontos.

O objetivo é alcançar a maior pontuação possível enquanto avança pela ilha.

## Tecnologias

- Unity
- C#
